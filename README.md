# Tavern Archive

SillyTavern 第三方扩展：**全局对话内容搜索** + 收藏 + 标签管理。

解决 ST 聊天搜索只能按标题、且只能逐角色进行的问题——直接搜索所有角色卡与群聊的对话**内容**，支持时间范围、发送者、角色卡范围等筛选，并可对聊天/单条消息收藏、打标签。

## 功能

- 全文搜索全部聊天内容（关键词、`"短语"`、`-排除`、正则、大小写敏感）
- 筛选：角色卡多选 / 群聊 / 发送者 / 时间范围（消息级）/ 收藏 / 标签
- 结果两种视图：按聊天聚合、按消息逐条；点击跳转并定位到具体消息
- 聊天级收藏（可写备注）、消息级收藏、聊天多标签（颜色/重命名/删除）
- 本地索引（IndexedDB），增量更新；收藏与标签存于扩展设置，随 ST 设置持久化
- 响应式 UI：桌面大弹窗，手机全屏 + 底部筛选抽屉

## 安装

1. SillyTavern 界面 → 扩展（积木图标）→ 「Install Extension」→ 填入本仓库地址
2. 刷新页面，顶部栏出现放大镜图标 🔍
3. 首次打开面板时按提示建立索引（聊天越多耗时越长，可后台进行）

也可使用斜杠命令 `/archive` 或 `/archive 关键词` 直接唤起。

## 要求

SillyTavern ≥ 1.12.0（依赖 `/api/chats/search` 端点）。只读聊天数据，不做任何修改。
